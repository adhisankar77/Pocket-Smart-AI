# PocketSmart AI — Your Smart Budget & Recommendation Assistant

**BCA Final Year Project | Front-end web application**

PocketSmart AI is a personal finance dashboard that helps users record income and expenses, monitor category budgets, review spending patterns, and receive simple rule-based recommendations. This project is intentionally built with HTML, CSS, and vanilla JavaScript so it can run locally without installing a framework or connecting to a paid API.

> **Academic note:** The “AI” recommendations in this version are generated by transparent rules from the user's recorded transaction data. It does not call a machine-learning model or a cloud AI service. Describe it in your viva as a rule-based recommendation prototype unless you add and document a real ML/AI model.

## Features

- Overview dashboard with income, expenses, balance, and savings-rate indicators.
- Category-based expense breakdown and progress bars.
- Add income and expense transactions through a form.
- Search transactions and filter by category.
- Edit monthly spending limits for categories.
- Rule-based insights for the largest expense category, budget overruns, and savings snapshot.
- A suggested 50/30/20 income allocation as an educational starting point.
- Responsive layout for desktop and mobile screens.
- Browser `localStorage` persistence: added transactions and edited budgets remain in the same browser on the same device.

## How to run

### Option 1 — Open directly
1. Download and extract the project folder.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. The dashboard loads with sample transactions for demonstration.
4. Click **Add transaction** to record an income or expense.

### Option 2 — Run with a local server (recommended)
If Python is installed, open a terminal inside the project folder and run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

No package installation, database, API key, or internet connection is required for the core app. The Google Fonts import in the stylesheet is optional; a system sans-serif fallback is provided.

## How to use the application

1. **Overview:** review the income, expenses, balance and savings-rate cards.
2. **Transactions:** open the full transaction list, search by description/category, or filter a category.
3. **Add transaction:** enter a description, amount, type, category and date. Save to update the dashboard.
4. **Budget planner:** choose **Edit budget** and enter a monthly limit for each category. Cancel at any prompt to stop editing.
5. **Smart insights:** read rule-generated summaries about the highest spending category, budget limits and recorded balance.
6. **Persistence:** refresh the page to see saved data. Data is stored only in that browser's local storage.

## Recommendation logic

The prototype uses simple explainable rules:

- **Expense totals:** sum transactions whose type is `expense`.
- **Income totals:** sum transactions whose type is `income`.
- **Available balance:** recorded income minus recorded expenses.
- **Savings rate:** `(income - expenses) / income × 100`, when income is greater than zero.
- **Category budget progress:** category expense total divided by that category's budget.
- **Highest spending category:** category with the largest recorded expense total.
- **Budget alert:** show a message if category spending exceeds its limit.
- **Suggested plan:** display 50% needs, 30% wants, and 20% savings as a general budgeting example, not a personalised financial recommendation.

## Data and privacy limitations

- The application stores data in the browser's local storage, not a server database.
- Data does not sync between browsers or devices.
- Clearing browser data may remove saved transactions.
- There is no user authentication, encryption, cloud backup, or multi-user support in this academic prototype.
- The included transactions and profile name are demonstration data. Replace them with your own project details before submission.
- Currency is displayed in Indian rupees (INR).
